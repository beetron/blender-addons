# Multi Fbx Exporter

**バージョン:** 1.0.4 · **作者:** Lazy Onigiri / bTro（nekorushi 氏のオリジナル版を更新）· **Blender:** 4.5 以降

選択したすべてのメッシュを、ワンクリックで**それぞれ個別の FBX ファイル**として書き出します。保存済みの FBX エクスポートプリセットを適用できるため、すべてのファイルを同じ設定で出力できます。多数の小物やモジュールパーツをゲームエンジンへ書き出すときに便利です。

## インストール

1. `Multi_FBX_Exporter_v1.py` をダウンロードします。
2. Blender で **編集 → プリファレンス → アドオン** を開き、右上の **⌄** メニューから **ディスクからインストール...** を選びます。
3. ファイルを選択し、**Multi Fbx Exporter** を有効にします。
4. パネルは 3D ビューポートのサイドバー（`N` キー）の **Lazy Onigiri** タブにあります。

## パネル

| 項目 | 説明 |
|---|---|
| **Folder** | FBX ファイルの保存先フォルダです。あらかじめ作成しておく必要があります。 |
| **Preset** | 適用する FBX エクスポートプリセットです。**None (Default Settings)** を選ぶと Blender の標準設定で書き出します。 |
| **Create Subfolders** | オンにすると、オブジェクトごとにサブフォルダを作成して書き出します：`Folder/オブジェクト名/オブジェクト名.fbx` |
| **Batch Export Selected** | 選択中の各メッシュを個別の FBX ファイルとして書き出します。 |
| **GitHub** | このリポジトリをブラウザで開きます。 |

## 使い方

1. **Folder** に保存先を設定します。
2. **Preset** を選びます。標準設定でよければ **None** のままにします。
3. 書き出したいメッシュオブジェクトを選択します。
4. **Batch Export Selected** をクリックします。

ファイル名はオブジェクト名になります（例：`Crate_01.fbx`）。

## FBX プリセットの作り方

1. **ファイル → エクスポート → FBX (.fbx)** を開きます。
2. スケール、軸、書き出す内容など、必要な設定を調整します。
3. 設定欄の上部にある **オペレータープリセット** の横の **+** をクリックし、プリセット名を付けます。
4. 作成したプリセットが、アドオンの **Preset** 一覧に表示されます。

## 注意点

- **書き出されるのはメッシュオブジェクトのみ**です。アーマチュア、エンプティ、ライトなど、その他の選択オブジェクトは無視されます。
- **各オブジェクトはワールド原点で書き出されます。** 書き出し中は位置が一時的に `0, 0, 0` に設定されるため、ゲームエンジン上でピボットが中心になります。書き出し後は元の位置に戻ります。回転とスケールは変更されません。
- **同じ名前のファイルがある場合は上書きされます。**
- オブジェクト名のうちファイル名に使えない文字は `_` に置き換えられます。
- 書き出し後、元の選択状態とアクティブオブジェクトに戻ります。
- 一部のオブジェクトで書き出しに失敗しても、他のオブジェクトは書き出されます。エラーは Blender のステータスバーに表示されます。
