# Blender Add-ons by Lazy Onigiri / bTro

Small Blender add-ons that speed up everyday modeling and game-export work. Both appear in the **Lazy Onigiri** tab of the 3D Viewport sidebar (press `N`).

## Add-ons

| Add-on | Version | Description |
|---|---|---|
| [Multi Fbx Exporter](Multi_FBX_Exporter/README.md) | 1.0.4 | Export each selected mesh to its own FBX file in one click, using your saved FBX export presets. |
| [Object Grouper](Object_Grouper/README.md) | 1.0.2 | Save named lists of objects and select a whole list in one click. The last object in the list becomes the active object, which is handy for rig exports. |

## Requirements

- Blender 4.5 or later

## Installation

1. Download the add-on's `.py` file from its folder.
2. In Blender, open **Edit → Preferences → Add-ons**.
3. Click the **⌄** menu in the top-right corner and choose **Install from Disk...**.
4. Select the `.py` file and enable the add-on in the list.
5. Open the sidebar in the 3D Viewport (`N`) and go to the **Lazy Onigiri** tab.

See each add-on's README for full usage instructions.
