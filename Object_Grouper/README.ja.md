# Object Grouper

**バージョン:** 1.0.2 · **作者:** Lazy Onigiri / bTro · **Blender:** 4.5 以降

オブジェクトのリストに名前を付けて保存し、**ワンクリックでリスト全体を選択**できます。毎回同じオブジェクトを Ctrl / Shift クリックする必要はもうありません。**リストの最後のオブジェクトがアクティブオブジェクトになる**ため、最後に Shift クリックしたのと同じ状態になります。リグをリストの一番下に置いておけば、アーマチュアがアクティブである必要があるエクスポーター（Auto-Rig Pro のエクスポートなど）をそのまま使えます。

主な用途：
- キャラクターの各パーツとリグをまとめて、エクスポートの準備をする
- 体のパーツや衣装のバリエーションごとにセットを作る
- よく選択するオブジェクトの組み合わせを保存する

## インストール

1. `Object_Grouper_v1.py` をダウンロードします。
2. Blender で **編集 → プリファレンス → アドオン** を開き、右上の **⌄** メニューから **ディスクからインストール...** を選びます。
3. ファイルを選択し、**Object Grouper** を有効にします。
4. パネルは 3D ビューポートのサイドバー（`N` キー）の **Lazy Onigiri** タブにあります。

## クイックスタート

1. 対象のオブジェクトを選択し、**最後にリグを Shift クリック**してアクティブにします。
2. **New Group From Selection** をクリックします。アクティブオブジェクトがリストの一番下に入ったグループが作成され、その名前が付きます（例：`rig_Group`）。
3. グループ名をダブルクリックして名前を変更します（例：`Character_Base`）。
4. 以降は **Select 'Character_Base'** をクリックするだけで、リグがアクティブな状態でグループ全体を選択できます。

## パネル

### グループ一覧
| 操作 | 説明 |
|---|---|
| **グループの行** | グループ名と、含まれるオブジェクト数を表示します。名前をダブルクリックすると変更できます。 |
| **行の矢印アイコン** | そのグループを選択します。 |
| **+ / −** | 空のグループを追加 / 選択中のグループを削除します。オブジェクト自体には影響しません。 |
| **▲ / ▼** | 選択中のグループを上下に移動します。 |
| **New Group From Selection** | 選択中のオブジェクトからグループを作成します。アクティブオブジェクトが最後に入ります。 |
| **Select '…'** | 選択中のグループのオブジェクトをすべて選択し、最後のオブジェクトをアクティブにします。 |

### オブジェクト一覧（選択中のグループ）
| 操作 | 説明 |
|---|---|
| **Active** マーク | 選択時にアクティブになるオブジェクト（最後のオブジェクト）を示します。 |
| **+** | 選択中のオブジェクトを追加します。アクティブオブジェクトが最後に入ります。リストの最後がすでにアーマチュアの場合、新しいオブジェクトはその**上**に挿入され、リグが最後のまま保たれます。 |
| **−** | 選択中のオブジェクトをグループから外します。オブジェクト自体は削除されません。 |
| **▲ / ▼** | 選択中のオブジェクトを上下に移動します。 |
| **⤓** | 選択中のオブジェクトを一番下に移動し、アクティブオブジェクトにします。 |
| **ブラシ** | シーンに存在しなくなったオブジェクトの項目を削除します。 |

### オプション
| オプション | 説明 |
|---|---|
| **Unhide Hidden Objects** | 初期状態でオンです。非表示になっているグループのオブジェクトを表示して選択できるようにします。オフの場合、非表示のオブジェクトはスキップされ、警告に一覧表示されます。 |
| **GitHub** | このリポジトリをブラウザで開きます。 |

## ヒント

- Select ボタンを **Shift クリック**すると、現在の選択を解除せずにグループを追加で選択します。
- グループを選択すると、ポーズモードなどからまず**オブジェクトモード**に切り替わります。
- **オブジェクト名を変更しても問題ありません。** グループは名前ではなく、オブジェクトそのものへの参照を保存しています。
- グループは **.blend ファイルにシーンごとに保存**されます。

## パネルの警告

- **赤い行：** オブジェクトが削除されたか、シーンに存在しません。ブラシボタンで整理できます。
- **「The rig is not last. Move it to the bottom.」：** グループ内のアーマチュアが最後の項目になっていません。リグを選択して **⤓** をクリックしてください。
- 非表示または除外されたコレクション内のオブジェクトや、選択不可に設定されたオブジェクトは、選択時にスキップされます。どのオブジェクトがスキップされたかはステータスバーに表示されます。
