# Blender アドオン集 by Lazy Onigiri / bTro

日々のモデリングやゲーム向けエクスポート作業を効率化する、小さな Blender アドオン集です。どちらのアドオンも 3D ビューポートのサイドバー（`N` キー）の **Lazy Onigiri** タブに表示されます。

## アドオン一覧

| アドオン | バージョン | 説明 |
|---|---|---|
| [Multi Fbx Exporter](Multi_FBX_Exporter/README.ja.md) | 1.0.4 | 選択した各メッシュを、保存済みの FBX エクスポートプリセットを使ってワンクリックで個別の FBX ファイルに書き出します。 |
| [Object Grouper](Object_Grouper/README.ja.md) | 1.0.2 | オブジェクトのリストに名前を付けて保存し、ワンクリックでまとめて選択できます。リストの最後のオブジェクトがアクティブになるため、リグを含むエクスポートに便利です。 |

## 動作環境

- Blender 4.5 以降

## インストール

1. 各アドオンのフォルダから `.py` ファイルをダウンロードします。
2. Blender で **編集 → プリファレンス → アドオン** を開きます。
3. 右上の **⌄** メニューから **ディスクからインストール...** を選びます。
4. `.py` ファイルを選択し、一覧でアドオンを有効にします。
5. 3D ビューポートでサイドバー（`N` キー）を開き、**Lazy Onigiri** タブを選びます。

詳しい使い方は各アドオンの README を参照してください。
